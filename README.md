# 🤖 GATE AI Assistant v2

### GDG PES College of Engineering Hackathon — Build Your Own Chatbot

🔗 **Live Demo:** https://gate-chatbot.vercel.app/

⚙️ **Backend API:** https://gate-chatbot.onrender.com

A full-stack AI-powered chatbot designed for GATE CSE preparation. The application provides topic-wise learning, AI-generated explanations, beginner-friendly guidance, quiz generation, and exam-oriented preparation using Google Gemini.

## Features

* 🎓 Beginner, Expert, and Quiz Modes
* 📚 Topic-wise GATE CSE Preparation
* 🤖 AI-Powered Responses using Gemini
* 🌙 Dark / Light Theme Support
* ⚡ Real-time Chat Experience
* 🔒 Secure Backend API Integration
* 📋 Practice Quizzes and Concept Revision

Built for the GDG PES College of Engineering Hackathon.
